# Contributing

Thanks for your interest! A few simple ways to help this project and earn quick achievements:

- Look for issues labeled **good first issue** and submit tiny PRs.
- Answer questions in Discussions and share helpful answers; maintainers can accept answers to help earn the Galaxy Brain badge.
- Star the repo if you find it useful — 16 stars earns the Starstruck badge.

Local workflow for contributors

```bash
git clone https://github.com/<owner>/<repo>.git
git checkout -b fix/your-change
# make small edits
git add .
git commit -m "Small fix: description"
git push -u origin fix/your-change
# open PR on GitHub
```

If you'd like us to run automated workflows that create small PRs (for Pair Extraordinaire, YOLO, Pull Shark), contact the repo owner.
